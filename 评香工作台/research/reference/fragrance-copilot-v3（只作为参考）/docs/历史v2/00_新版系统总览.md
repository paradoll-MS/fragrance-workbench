# 新版系统总览（v2）

更新：2026-10-28  
依据：`工作簿1.xlsx` Sheet1 / Sheet4  
状态：**定稿；开始重构**

## 1. 一句话

把客户带来的 brief、会议、聊天、对标链接/图片和补充资料，整理成**项目简报 + 可检索的项目故事 + 若干子项目**；每个子项目按六类任务之一推进，经**品类→规范类/新类→硬筛（不含 C）→C/AB 计分**给出可解释的香精候选，最后走到**初样 / 终样 / 入库**。

## 2. 对象

| 对象 | 含义 | 不是什么 |
|---|---|---|
| 项目 Project | 一个客户带来的一个商业请求 | 不是一个香型 |
| 子项目 Subproject | 项目内一条独立推进的香型/任务目标 | 不是部门工单 |
| 部门任务 DepartmentTask | 打样/寄样/分析/调香/法规/质量/入库 | 不是子项目类型 |
| 外部样品 ExternalSample | 客户寄来的实物样品/竞品 | 不是我们的香精 |
| 资料 Artifact | brief、会议、微信、链接、图片 | 不是结论 |
| 决策 Decision | 人工确认/修改记录 | 不是 LLM 输出 |

**命名**：UI 与数据库统一用「子项目」（`subproject`），不再用「方向」作为主词。

## 3. 六类子项目

1. `find_product` 找一个香：精确品牌+产品+版本，先查库；有就推，没有再转仿香/创香。
2. `match_sample` 对一个香味：客户寄样，评香对香/标签检索；可以就推，不行再转。
3. `recommend_simple` 推荐香·简单厂家：品牌/大牌仿香、A1/A23、香调、价格硬筛；表现力只展示原文。
4. `recommend_brand` 推荐香·品牌客户/创香前试香：A1/A23/B硬筛（不含 C）；C 每命中 +3，AB 每命中 +1。
5. `modify` 改香：锁定被改香精编号+改动要求，交调香。
6. `create` 创香：把调香师需要的信息+评香参考香（含备注）交调香。

一个子项目**只有一个主类型**；可以随进展升级并保留历史（如 `recommend_brand → create`）。

## 4. 硬规则

- 所有子项目先定 **三级品类 L3**，再映射到 **规范类（18）** 和 **新类（12）**；推荐只在新类内。
- 价格是必填；默认允许 **t=20%** 的弹性上限。
- **C 只计分，不做硬筛**；目标 C 可以为空；有 C 时按类型/口径命中，一个品牌推荐子项目可以有多个目标 C，候选命中任意一个即可。
- **C 计分**：每个命中的目标 C **+3**；AB 每个 distinct +1；`总分 = C命中数×3 + AB命中数×1`。
- 大牌仿香：
  - 精确到具体产品 → `find_product`；
  - 只到品牌 → `recommend_simple` 的品牌过滤；
  - 品牌 + 多个指定产品 → 每个指定产品拆一个 `find_product`，剩余品牌需求拆一个 `recommend_simple`。
- 子项目香型需求里 **A1 明确就硬筛**；多个 A1 时 **命中任意一个即可**。没有 A1 时，A2/A3 明确则按 A2/A3 宽筛。
- 初样可绕开法规/稳定性/表现力三项默认要求，但保留风险提示并由评香放行；终样/入库逐项核对。
- V2没有做做实物库存、不做数据回流。

## 5. 主流程

```text
项目
→ 资料箱：上传/粘贴/链接 → 解析 → 类型/角色标注 → 备注
→ 项目简报：六组字段 + 证据 + 重点关注项
→ 项目故事：时间线/原文/决策，供问答引用
→ 拆子项目：香型 + 任务类型
→ 子项目：L3 → 规范类/新类；价格；A1/A2/A3；品牌/产品；目标 C
→ 推荐/对香/改香/创香
→ 硬筛 → C 类型前提 → C×3 + AB×1 计分 → 结果
→ 部门任务：打样/寄样/分析/调香/法规/质量/入库
→ 终点：初样 / 终样 / 入库
```

## 6. 人工节点检查/操作（评香）

1. 附件类型/备注是否正确；
2. 项目简报关键字段；
3. 子项目拆分与主类型；
4. L3 → 规范类/新类；
5. 目标 C（只能一个）；
6. 候选短名单/淘汰；
7. 终点选择与初样放行。

## 7. UI 五屏

1. **项目列表**：新建、最近项目、状态。
2. **项目工作台**：资料 / 简报 / 子项目 三个 tab；默认显示“下一步”。
3. **子项目详情**：顶部品类/任务/价格/终点；主体推荐或任务；右侧折叠调参。
4. **推荐结果**：一张表，硬筛条件、C、AB 命中、价格、标签；点开解释。
5. **故事与问答**：时间线 + 引用问答抽屉。

不做全量树、不做多列仪表盘、不把低频字段铺在首屏。
