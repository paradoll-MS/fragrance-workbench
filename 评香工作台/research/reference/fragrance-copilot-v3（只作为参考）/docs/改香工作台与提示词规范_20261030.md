## 四项建议
- A采纳：标签及关联标识在集合/字典操作前校验类型。仅从明确id/value或关联key恢复标识，不把label当编号，不静默丢弃异常来源；校正记录留存。原失败g_d85ac3342a0045e3离线重放经3处类型归一化通过校验，没有重新调用模型，也没有覆盖原运行。
- B采纳：空白、拆分、单字转录校正分别留痕，保留原model_quote，拆分保留索引与组合校正方法。结果/故事统计引用次数和独立原文段；UI区分校正类型。原文定位成功不等于语义判断正确，数字、否定等保护没有放宽。
- C未采纳：不让缺少有效理由的B继续计分，B影响排序且可人工设为硬筛，不能为减少报错而豁免证据。
- D部分采纳：增加软容量预检、粗略范围和风险提示，中高风险要求紧凑输出。不会仅按既有子项数量拒绝项目、截断资料或停用标签名称/编号校验。现有数量无法确定本轮新增目标与增量输出量，估计不是性能承诺。
