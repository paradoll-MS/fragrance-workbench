# Workspace ／ 工作台、模型与实现

## 1. 评香看到的内容

1. **项目页**。左侧项目、子项和轮次。主区顶部显示本项目能做的下一步，等待内容随子项折叠。资料区显示原件、读到的页段及未读位置，保留「补录文字」「重读」「拆解需求」。反馈入口把旧实发和新反馈放在一起。
2. **拆解确认**。每张卡只显示目标、应用、款数、价格、交期及原文入口。稀疏信息允许一键接受，冲突可展开。用户可合并、拆分、改关联或新增。显示汇总款数和必选款，项目共同条件只录一次。
3. **工作台**。当前步骤占主视图，已完成步骤收起。选香布局按 [ABC 选香](recommendation-ABC选香.md)。需求标签按「必须」「偏好」「避开」显示，空项收起。像「薰衣草或玫瑰」这样的组合直接按原意呈现，关系可在编辑时展开。相似度是对香卡的下拉项。多款计划用目标位显示进度，每个并行方向有「选定香精」「启动创香」「基于此香修改」「启动仿香」「暂存」中适用的动作。
4. **开发与检查**。试作、实际样状态、历史评香意见出现在一张卡。检查按「待派发」「待部门」「已核销」「失败/待核对」呈现。每条可打开条件、凭证与来源。放行按钮显示该行缺哪项，评香可继续其他行。
5. **寄样**。选目标和寄样等级，显示实际样品形态、单位、数量、准备状态及随附文件。初寄提示待办和剩余正式交付；已寄栏读实际回执。复寄从实寄行进入，可重新选地址和数量。支持分批。
6. **界面文字**。按钮使用具体动作，信息用名称与值。无资料的部分先收起。错误给对象和可操作的下一步，例如「原实发有 2 款，选择修改对象」「第 3 页未读，可补录文字」「该款缺同版本报告」。刷新后显示已保存的人工决定。

## 2. 两种模型节点

### Parse ／ 资料与需求

- 先读取常用格式。TXT/Markdown 保留段和编号，DOCX 按正文与表格顺序，PPTX 按幻灯片及文本块，XLSX 按工作表和单元格，PDF 按页输出。图片和无文字页走 OCR/视觉，音频通过已配置 ASR，网页入口保留 URL 与抓取状态。失败页可定向重读，用户也可粘贴原文。视觉描述、转写和可校验文字引用在数据上各有类型。
- F03 对同批资料和相关项目上下文调用一次语义 Parse，提取独立交付目标、角色与来源、项目共享和子项字段、新旧要求的替代关系、跟进类型建议。给每条事实提供可定位引用；日期、范围、量价及百分比各自建模。三调结构归香气描述，未来意向记为后续考虑。客户额外要求和普通供样约定分别保存到对应字段。
- 短输入先试 Flash，跨文档反馈和结构冲突场景候选用 Pro。源较长时按资料/章节形成附定位的分批调用，再汇总去重并列出未覆盖资料。不能读取的文件仍显示在页面，用户可确认带缺口的草案。模型每阶段最多一次有界格式/引用修复，模型失败转手填或重试。
- 验证包括 schema、引用范围与真实文本、原始数字/否定、已有 ID 存在性、项目事实或变更的作用域。明显错误的字段留草案问题。用户确认才进入业务状态。提取附候选应用与审查品类，程序查字典，保留歧义供人选择。F05 用此确认后的信号判型。

### Targeting ／ 需求标签

- 输入为当前轮已确认的香气描述、选用应用品类及本模式需要的业务背景，加合法 A/B 字典、相关 C 子树、判定说明和别名。已有身份、价格与明确目录由规则带入。短词唯一同义可直接映射；品牌和概念语义走模型。
- 输出为 typed 标签、label 和 id、category_id?、目标极性、建议优先级、证据片段及未知词。限定已知词典。名称与 ID 都核对，名称唯一可确定性纠正并记日志，重名、跨应用或无依据进入待确认。A1 是气味对象，A2 是香韵，A3 是整体香调，B 是风格/感受，C 是该应用下可定位的叶。原话仅列三调时，A1/A2 需要独立主体依据；A3 需要整体现象的独立证据，三调组合可辅助 B/C。
- 允许返回空、局部映射或待补词。用户可以手绑合法词并直接重算。打分、确认关系、证据核销、库存和派发由程序处理。F08 将人工修订存为项目反馈。香精资产批量贴标属于 Targeting 的离线受控入口，写人工复核或导入层。

## 3. 模型连通与配置

- Paratera 模型目录查询成功，返回 91 个条目。用无业务数据的合成短 JSON 冒烟，`DeepSeek-V4-Flash-0731`、`DeepSeek-V4.1-Flash`、`DeepSeek-V4.1-Flash-1017`、`DeepSeek-V4-Pro-0813` 均返回期望的结构与空价格，传入 `thinking.type=disabled` 时此次响应均无 reasoning_content。
- 第二轮用 0731 和 V4.1 Flash 两个候选先比短词与品牌 Targeting，1017 作对照；跨文档 Parse 同时比 Flash 和 Pro。扫描页从 `DeepSeek-V4-Flash-Vision-Exp` 或 `GLM-4.6V` 中试读。此次探针校验了连通与结构，提取质量、视觉能力和可用上下文仍按业务样例选定。
- 每个节点配模型 ID、参数、上下文/输出预算、超时、重试、允许的降级模式与字典版本。保存有效配置、调用用时、可用响应和校验结果。前端可显示 run_id 和重试。服务端加载密钥，刷新指纹保护人工改动。只把必要文本或页面发到模型，剔除收件信息和与任务无关的敏感字段。
