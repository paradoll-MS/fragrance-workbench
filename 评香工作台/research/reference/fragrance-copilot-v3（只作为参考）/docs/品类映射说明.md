# 三级品类 → 规范类 / 新类 映射

更新：2026-10-28　|　机器可读：`data/品类映射.json`、`data/规范类默认指标.json`

## 口径

- **规范类**：统一逻辑使用的 18 个应用默认分类（身体香氛类、点燃扩香类……工业工艺类）。
- **新类**：当前香精库使用的 12 个新类（个人香氛、身体洗护……工业遮味）。
- **单值映射**：每个三级品类有且只有一个规范类、一个新类；但这是业务上的“唯一”，不是数学上的一一对应（injective）。56 个三级品类归并到 18 个规范类和 12 个新类，必然多对一。
- `K056 其它产品` 不强行归入某个规范类/新类，保留为待按实际用途确定。

## 需要特别注意的分界

- **K011 空间喷雾 vs K041 空气清新喷雾**：规范类都属于「空气护理类」，但新类分别为「空间香氛」和「空清消杀」；前者是空间香氛产品，后者是空气清新/除味产品。
- **K005 蜡烛 vs K006 线香 / K043 卫生香**：规范类都属于「点燃扩香类」，但新类分别为「空间香氛」和「空清消杀」。
- **K042 蚊香 / K044 杀虫喷剂**：叠加身份为农药/防蚊驱虫，不能只按香氛处理。
- **K045 消毒**：叠加身份为消毒产品，香味不能替代消毒功效。
- **K046–K049 婴童**：规范类仍按身体淋洗/身体驻留/异味管理走，但新类统一为「婴童护理」，并触发儿童法规路径。
- **K050–K052 宠物**：规范类仍按身体淋洗/异味管理走，但新类统一为「宠物护理」，不按人体化妆品处理。
- **K053–K055 工业**：规范类为异味管理/工业工艺，新类统一为「工业遮味」。
- **K037 洗洁精果蔬净**：叠加食品接触身份，不能只按硬面清洁。
- **K056 其它产品**：没有唯一规范类/新类，必须回到实际用途再判。

## 用法

1. 先把客户产品归到 K001–K056 的三级品类；
2. 用本表得到 `norm_class` 与 `new_class`；
3. 用 `new_class` 接香精库的 A/B/C 新类；
4. 用 `norm_class` 去 `data/规范类默认指标.json` 取该类的表现力/稳定性/法规基线；
5. 再按销售地取 `regulatory_by_region` 的法规明细。
