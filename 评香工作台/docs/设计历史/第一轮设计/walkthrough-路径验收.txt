Walkthrough ／ 第一轮路径验收

验收范围
本轮用真实文本和只读库结果检查字段来源，逐步代入人工决定与模拟部门回执检查契约。
下文的模拟编号和事件只用来走查。真实工单记录只按其原始字段解释。
每条路径按「来源 → 操作 → 数据落点 → 恢复或终点」检查。

01. 常规推荐 ／ 小推 03「桂花、柔顺剂、90 以内」
├─ 实际来源：小推 03 的原文。F02/F03 保留柔顺剂、桂花、明确上限及各自引用。确认 CAT_07，审查可建议 fabric_deposition，地区、剂量和交期未知可先搜。为试跑显式把 90 确认为 CNY/kg。
├─ F08 唯一标签 A1_c3bf4b4601（桂花）；评香确认主香型硬筛。F09 对当前 ABC 资产按冲突隔离、CAT_07、正数库价 ≤90、原生 A1 过滤，结果为空。
├─ 单条件诊断实查：关价格可看到 5 款，包括 2051（173.79）和 LJF1367CLJ（区间原文，未作数值）。关品类仅 8397（78.86）。关桂花有 71 款，价格与品类符合但不满足当前主香型条件。
├─ 评香可继续看替代方案。保留客户上限，单列 8397 为跨品类探索候选，仍要确认应用和价口径；或暂存。F08 写新查询与 targeting_feedback，原查询不被覆盖。
├─ 模拟补来一款应用和价格均符合的库香。F10 选香 → F17 确认审查品类、用途和待检查条件 → F19/13 派准备齐全的检查 → F14/18 回凭证 → F20 正式放行。
└─ 已入库，F21 准备时发现样品库存不足。模拟备样回样号后预留，F22/14/23 实发才完成目标。缺剂量只等依赖该字段的检查，不撤销先前选香。

02. 必选款 + 多款推荐 ／ 小推 01「TF 白麝香、女香 5–7 款」
├─ 原文要求同组合 5–7 款含一款 TF 白麝香，另要清新、淡雅、微甜的女香；只寄 18% 加香小样。F04 确认共享供样条件、必选 Goal、其余目标数；未来人宠及个护仅记意向。
├─ 必选走 find_product。真实目录 PR_0060 为「待核验」，只有 JKP1745AJK strong_candidate，无确认关系。F06/F09 显示待核身份/关系，不能自动选。人工可核验后登记，也可确认目标与实际分析样开始仿香。
├─ 其余目标用品牌选香。模拟评香确认总数 5，其中白麝香 1，其余 4。从库香选 2、原创 1、基于原香改 1，按 Goal/PlanSlot 绑定。缺概念、配方或分析样只等待各自目标。
├─ 模拟关系核验补齐并确认具体版本。精确库香正式放行；品牌开发分别经调香、验收、入库和客户二查。各自的版本和回流地址可见。
└─ 模拟已正式寄 3 款，剩余 2 款继续，项目 active。18% 是样品添加量，实际数量在寄样时确认，只有合格实发才核销。未确认齐发要求时允许分批。本次寄含香小样，原液不会混进寄样清单。

03. 精确产品 / 无命中仿香 ／ 小推 02「Le Labo 全系列，13 与 33 必须有」
├─ F03 将 13、33 作为两个明确目标，其余系列交给目录推荐。F06 用品牌范围解析为 Another 13（PR_0082）及 Santal 33（PR_0081）。两身份已 verified；对应的现有 5/12 条库关系均待核验，没有精确结果。“13”需要品牌范围和具体产品确认。
├─ 模拟 13 完成关系与价格确认。F10 选库香 → F17–F20 → F21–F23 正式寄样。试点初寄时 F20 返回路径不可用，另外两个方向仍可做。
├─ 模拟 33 缺确认关系，评香选择仿香。F12 等分析实物。到样后 F13 派分析，F14 回正确样品对应的 GC。错样报告留在 inbox，待更正。评香确认 GC 后继续调香。
└─ 模拟通过后先入库，F16 按真实父目标位返回编号/版本。F17 从父需求重新生成二查，适用入库凭证可复用。客户价格上限 300 随父项目保留，需要确认当前报价。正式实发补齐目标。

04. 对香跳检索 / 退回试作 ／ 情绪怪兽线香场景
├─ 参考真实工单 YPGD-20260612-0011。要求为线香，备注有 SYP702BSY「雨后当归」降到 200 以内，朱雀有两条参考配方；历史正文提到 IFRA，不能直接核销。该单意见与实寄号不可互换。
├─ 模拟一条以实物为主的无可用配方需求。F07 先登记待收样，相似度留空。评香点「直接开发」跳检索；F10 审计跳过动作。选复现则 Job 等分析样，原始需求和价格目标保存。若只取灵感且已能明确方向，创香可先派，不生成分析任务。
├─ 模拟到样 → F12/13 → GC → 调香；试作 1 回了配方版本但样品晚到，先等备妥。F15 驳回并记录具体修改，生成 iteration 2，客户轮次保持。
├─ 试作 2 通过 → 按新版本建入库 CheckSet，旧版本凭证不自动移用。模拟应用结果晚到，其他检查先回。入库确认后回父项 → F17 二查。
└─ 模拟初寄：有效合规项通过，批准白名单内一项表现力测试仍 pending。经评香确认后初寄，目标未完成。后续结果若失败，正式寄样保持等待，评香可换香、复测或派改配方；新合法版本通过后用正式实发完成。

06. 品牌风格、双品类 / 续荐、复寄、承袭改香 ／ 小推 05 地面走查
├─ 「雅顿绿茶风格」保留为风格参照。F04 拆无火与蜡烛的独立交付目标，两者应用可同 CAT_06；审查分别是 passive_diffusion 和 burning_diffusion。确认蜡烛两种实际体系是否需分别交付。客户茶香香基宣称生成待审核要求；30ml 样品、10% 添加量分开。180 作目标价，未主动加容差硬筛。
├─ 模拟无火先完成正常选香、检查和寄送。客户反馈「继续推」时新增 Round，剩余旧目标或新增目标由评香选；当前方向明确拒绝项随轮次，旧实发保留。客户「复寄」时 F04 从旧 ShipmentLine 创建独立 resend 目标，检查当前版本、收件和有效凭证后重寄。
├─ 模拟客户要求改「无火版上次实寄样」。只有一条有效实发时关联 shipment_line_id；多条时让评香选；回执暂未同步时可先存改动。此时不会选用搜索候选，也不会覆盖原 Round。
└─ 新承袭项确认版本后走改香、入库二查、寄样。原蜡烛方向继续独立推进。旧项目如果曾完成，只在新增必需目标时恢复 active。

07. 内部开发与替代 ／ 模拟
├─ invent：负责人手填原创方向、应用与款数，未给价格先继续。F01/04 → F12 确认 → 调香 → 验收 → 入库检查 → 中台入库回执。F16/24 完成内部 Goal，不创建寄样任务。

08. 历史选香资料能否用于第二轮 ／ YPGD-20260615-0028
├─ 已读原文与工单快照。线香，三个独立主题、每主题两款，价格 300 以内，15ml。方向分别以清旷冷杉凉意、苔藓苦根泥土、旧木树脂盐感为主。按三目标而非六个独立需求拆，实寄样关联到对应方向需要来源或人工判断。
├─ 样品级资料有 6 行填报寄样及运单引用，回看以历史证据保存。反馈是客户香型储备，不能当作最终采纳。仅凭这些记录无法断言每个编号属于哪个主题。
├─ 六个编号中，在当前 ABC 主视图仅查到 LYP1498BLY，标 CAT_01，快照价格 306.39。不能据此判断当时选香超价/不适用。其余编号当前不在池内，说明逐案复盘要先查库范围和历史价格/用途，改评分不会补出库外资产。
└─ 第二轮先在当时可用范围内跑候选，再揭开历史选样和后续反馈。优先对比三个方向各自的硬筛、关联解释、是否应展示跨品类探索，记录缺口及可复现的改法。
