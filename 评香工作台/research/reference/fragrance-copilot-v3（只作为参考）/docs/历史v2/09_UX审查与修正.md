# UX 审查与修正

更新：2026-10-29

## 1. 审查发现

按“业务员/评香第一次用”的路径走一遍，主要问题：

1. 资料、子项目都删不掉；误传只能新建项目重来。
2. 简报、拆分、推荐都要先点按钮；用户不知道下一步该做什么。
3. LLM 调用没有成本/耗时可见性；长任务只弹一个 toast。
4. 推荐条件改了以后结果不自动刷新，容易看旧结果。
5. 图片/音频上传后只“保存”，没有自动多模态理解。
6. 终点检查客户要求和默认要求混在一起，客户强调项不醒目、没有明细。
7. ABC 修改靠 prompt 输入，不知道有哪些可选值。
8. 没有香精库直接检索入口；评香想核一个编号要绕。
9. 危险操作没有确认；删除/替换容易误点。

## 2. 已修正

- 资料删除、子项目删除、项目删除 API + 界面；删除前确认。
- 进入项目简报自动生成；进入子项目自动拆分；条件齐备后自动推荐。
- 子项目条件保存、C/A 修改后自动重跑推荐。
- 项目头部显示 LLM 用量：调用次数、tokens、估算成本、累计耗时。
- 上传图片自动走 Qwen VL；上传音频自动走 ASR；扫描 PDF 自动抽取页面图片走视觉。
- 解析失败保留原件，显示 `parse_error`，可重新解析。
- 终点检查客户指定项置顶，红色高亮，带原文/明细；默认指标在后。
- A1/A2/A3、C 改为搜索+多选选择器；C 支持多选。
- 香精库检索入口：编号/名称/品牌标签直接查。
- 价格弹性、C 权重、AB 权重可调；默认 C=3、AB=1。
- 重新拆分改为“确认后替换”，不再无提示重复生成。
- 上传/LLM/推荐有进行中状态，避免看起来没反应。
- 只有“重新解析”保留为手动兜底；分类、视觉/ASR、简报、拆分、C 映射、推荐、默认任务、终点清单都在首次进入时自动执行。保留“保存条件/改 A、C/刷新推荐”作为人工调整，不作为首次调用入口。
- 资料卡增加“查看”：图片/音频/PDF 内嵌预览，其他格式可下载原件；同时显示已解析文本。
- 项目工作台顶部常驻“项目简报”小卡；没有简报时自动生成。
- 旧子项目没有子简报时，按项目简报自动补子简报/handoff；品类为空时从项目简报回填。

## 3. 仍需补

- 真正 SSE/事件流：当前是同步请求 + 状态提示，长 LLM 任务还不能逐字流式显示。
- 删除撤销/回收站。
- 项目列表上的批量操作（单个项目删除已在项目工作台提供）。
- 视频关键帧、批量上传、拖拽排序。
- `match_sample` 的标签检索候选列表还可继续做成专门页。
- 终点核对批量确认/批量导出。
- 移动端细调。
