# 品类映射与默认指标（v2 接入说明）

更新：2026-10-28

## 1. 三套分类

| 层 | 用途 | 数据 |
|---|---|---|
| 客户三级品类 K001–K056 | 理解产品、法规、默认要求 | `data/品类映射.json` |
| 规范类（18） | 统一逻辑里的应用分类 | `data/品类映射.json` / `data/规范类默认指标.json` |
| 香精新类（12） | 香精库检索硬门槛 | 同上 |

## 2. 单值映射

每个三级品类有且只有一个规范类、一个新类；不是数学一一对应。K056 其它产品待定。

## 3. 默认指标

`data/规范类默认指标.json` 提供：

- `ifra`、`allergen`、`sds_coa`；
- `performance_codes`（P1–P11）；
- `stability_codes`（S1–S7）；
- `regulatory_by_region`（9 个销售地）。

稳定性默认：45℃ / 4℃ / 3 次循环 / 光照 8 周；项目可覆盖。

## 4. 在 v2 的使用

1. 子项目填 L3（可直接输入，也可从 datalist 选 K 表里的三级品类）；
2. 先按 `data/品类映射.json` + `category_map` 的 **level3/aliases** 精确/包含匹配；
3. 字典没命中时调用 `map_category.md`，让 LLM 从 56 个 K 码里选一个，写 `norm_class/new_class` 和 `category_confidence`；
4. 置信度低于 0.7 时 UI 标红“品类置信度低，请核对”，人工用 datalist 改；
5. 无新类不允许推荐；
6. 终点检查读规范类的三项默认要求。

### 常见别名覆盖

`无火香氛 / 无火扩香 / 藤条香薰 / 液体香薰 / 香薰液 / 扩香液 / 挥发液` → K007 藤条挥发液（无火扩香类 / 空间香氛）。  
`香薰蜡烛` → K005；`车载香氛` → K010；`扩香机/香薰机` → K009；`晶石/石膏` → K008；`空间香氛/空间喷雾` → K011。

### 规则文件在哪

- 映射数据：`data/品类映射.json`
- 运行时表：`data/app.sqlite3` 的 `category_map`
- 兜底 prompt：`prompts/map_category.md`
- 完整 56 行说明：[品类映射说明](品类映射说明.md)
- 18 规范类默认：[规范类与地区默认指标](规范类与地区默认指标.md)
