Workflow ／ 平台主链

评香工作台 /projects
├─ 新建项目，粘贴文字或上传资料
│  ├─ TXT / DOCX / PDF / PPTX / XLSX → 文字、段落、页、幻灯片或行
│  └─ 图像或扫描页 → 可选择视觉读取；原件与每处定位留在本地
├─ 拆解所选资料
│  └─ 当前资料 + 已确认方向 + 已记录实发 → 入口、字段、来源、未决项
├─ 修订并确认
│  └─ 生成轮次与方向；实发归属未明可先存，执行时定位
├─ 每个方向独立处理
│  ├─ 精确找香 → 产品／版本 → 确认库香或启动仿香
│  ├─ 常规推荐 / 品牌推荐 → 带品类、价与香气目标进选香
│  │  └─ 选库香、基于原香改香；品牌推荐还可创香
│  ├─ 对香 → 确认可用实物 → 选库香或跳过检索直接开发
│  ├─ 改香 → 确认原香与可调用版本；不可用时可转对香
│  ├─ 主动开发 → 创香 → 入库终止
│  └─ 复寄 → 绑定实发香精与版本
├─ 开发线
│  ├─ 仿香先派分析，确认 GC 回执再派调香
│  ├─ 创香、改香直接派调香，试作可退回迭代
│  └─ 评香通过 → 模拟入库检查 → 入库 → 客户方向返回交付
├─ 交付线
│  ├─ 填样品形态与量 → 派备样 → 确认实物回执
│  ├─ 初寄 → 寄样回执 → 记实发，继续保留正式交付
│  └─ 正式寄样 → 客户检查回执 → 派寄 → 记录实发 → 计入目标款数
└─ 续荐、改香或复寄
   └─ 新资料走新轮次，引用旧方向或具体实发，旧记录保留

模拟中台 /mock-platform
├─ 查看下发简报和部门检查条目
├─ 手填通过、退回；可设置新任务默认值
├─ 项目端确认回执后推进；失败重派该步骤，已通过项可继承
└─ 资产编辑、报价、查询反馈与回执存审计记录

说明
原始项目、资料和草案与正式轮次各有存储位置。项目步骤可暂存恢复。
本地生成的报告、版本、入库号、实物样和物流含 MOCK 标记。
