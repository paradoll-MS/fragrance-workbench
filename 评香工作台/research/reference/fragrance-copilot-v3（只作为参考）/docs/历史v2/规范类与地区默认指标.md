更新：2026-10-28　|　机器可读：`data/规范类默认指标.json`

## 组合规则

任意「规范类 × 销售地」= 该规范类的**表现力明细 + 稳定性明细 + 法规基线** + 该规范类在该销售地的**市场法规明细**。

- 稳定性默认口径：高温 45℃、低温 4℃、冷热循环 3 次、光照 8 周；项目可用客户方案覆盖。
- F1 IFRA 与 F3 SDS+COA 为各分类各市场均需；地区表只列随「分类×销售地」变化的部分。
- 表现力、稳定性只随规范类走；法规随「规范类 + 销售地」走。

## 稳定性默认

| 代码 | 默认要求 |
|---|---|
| S1 基料/基质相容 | 实际基料 + 实际添加量 + 工艺 + 包装下，48h 无析出/分层/浑浊/变色/异味 |
| S2 温度稳定 | 高温 45℃、低温 4℃、冷热循环 3 次，外观/气味合格 |
| S3 光照稳定 | 强光/氙灯 8 周不变色、不褪香 |
| S4 燃烧/闪点 | 点燃类/气雾核对闪点、燃烧安全、排放 |
| S5 包材相容 | 与实际包材 45℃ 下无渗漏/腐蚀/变形 |
| S6 批次一致 | 与批准样对比色差 ΔE 与气味一致，留样可追溯 |
| S7 供货周期 | 样品/生产/库存/起订量/交期确认 |

## 使用注意

- 这是**默认指标**，不是每个项目都必须全部做完；客户方案、品类特性和风险评估可以覆盖或加严。
- 法规条目是资料准备方向，不替代具体法规原文、版本核对和专业评估。
- 无法确定规范类时，先回到三级品类；无法确定三级品类时，不要用本表硬套。
