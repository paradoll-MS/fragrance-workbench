# 重点关注信息经验（LLM 参考）

更新：2026-10-28  
用途：给整理香精项目资料的 LLM 一份“注意力清单”。  
它不是问卷，不要求每个项目都把下面所有项找齐；它的作用是：**看到相关信号时知道该停下来确认，没看到时知道该标“无/未知”，而不是用常识补。**

---

## 一、可直接放进 system prompt 的版本

```text
你在整理香精项目资料时，先建立“事实层”，再做“判断层”。

不要为了填满字段而推断。对下面每个关注项，只输出五种状态：
- explicit：资料里有明确文字/数字/决定；
- partial：只提到一部分，缺少口径、对象或条件；
- inferred：从上下文可合理推断，但没有明文；
- absent：资料里没有出现；
- conflicting：不同资料说法不一致。

对 explicit / partial / conflicting 的项，必须带原文摘录和来源；
对 absent 的项，不需要编一个答案，但要在“待确认”里说明它是否影响下一步。

重点关注：
1. 资料是谁给的、什么时候、哪个版本、对哪个产品/市场；
2. 这是哪类任务：选香、仿香、创香、改方、法规、检测、打样、寄样、出资料；
3. 有没有寄样/送样/自提/补样，走到哪一步；
4. 最终销售地/市场，以及对应的法规辖区；
5. 产品受众画像：年龄、性别、敏感人群、婴童/宠物、渠道；
6. 价格要求：目标价/报价/样品金额，币种、单位、含税、数量条件；**没有单位的报价数字默认元/公斤**；
7. 法规要求：市场、品类、IFRA、过敏原、SDS/COA、注册/备案；
8. 产品宣称：原话、对象、证据、是否对外；
9. 表现力要求：强度、爆发、扩散、留香、平衡、层次，及评价阶段/载体；
10. 稳定性/相容性要求：基料、剂量、温度、光照、包装、观察项；
11. 对标样及对标目的：仿香、同款、近似参考、风格参考、竞品分析；
12. 使用场景/基料/加香比例/工艺/包装；
13. 交付物、数量、时间、语言、标签/收件要求；
14. 当前状态：候选/推荐/已寄/已收到/已试用/已确认/已选中；
15. 冲突、缺口和下一步该问谁。

不要因为资料没写就认为“客户没有要求”；也不要因为资料写了“要”就认为“已经做到”。
```

## 二、总原则

1. **先任务，后字段。**  
   同一句“要高级感”，在选香、仿香、创香、法规核查里要追的东西不同。先判断任务类型（T01–T14 或未知），再决定重点。

2. **事实、目标、偏好、推测分开。**
   - 事实：已经发生、可核验；
   - 目标/约束：希望达到或不能违反；
   - 偏好：单方倾向；
   - 推测：销售/评香/调香判断；
   - 待办：计划，不等于完成。

3. **任何关键项都问“口径”。**  
   价格问单位/币种/税；留香问载体/时点/方法；法规问市场/品类/版本；稳定性问基料/温度/包装；寄样问数量/收件人/状态。

4. **缺失也是结论。**  
   “资料没有写价格”本身是重要信息；不要用“大概”“通常”“应该”补成事实。

5. **不要死磕。**  
   如果某个关注项与当前任务无关，或资料里确实没有，标 absent 即可；只有在它会影响选香/报价/合规/交付时，才升级为追问。

## 三、关注清单

### P0：不确认就容易做错方向

#### 1. 资料身份与版本

- **为什么**：同一项目可能有旧 brief、新邮件、微信补充；用错版本会全盘错。
- **看什么**：谁写的/谁说的、日期、版本号、收件人、附件、是否转发、是否会后确认。
- **不要**：把会议纪要当客户最终确认；把旧版 brief 当最新；把销售转述当客户原话。
- **输出**：`source_type`、`author/speaker`、`timestamp`、`version`、`status`。

#### 2. 任务类型与项目阶段

- **为什么**：选香、仿香、创香、改方、法规、检测、打样、寄样、出资料，需要的信息不同。
- **看什么**：客户要的是“找现样”“仿某款”“做一个新概念”“改旧配方”“查法规”“寄样”“出资料”中的哪一种；是否多任务并行。
- **不要**：把“推荐/候选”当“已选中”；把“项目结束”当“样品达标”。
- **输出**：`task_type`（T01–T14/unknown）、`stage`、`next_action`。

#### 3. 有无寄样 / 样品状态

- **为什么**：寄样是业务事实，但“安排寄”“已寄”“已收到”“已试用”“有反馈”“已确认”是不同阶段。
- **看什么**：寄了什么（内部号/版本/数量/规格）、寄给谁、哪天、快递/自提/补寄、是否收到、是否有反馈。
- **不要**：把“下周寄”写成“已寄”；把“已寄”写成“已收到”；把“收到”写成“认可”。
- **输出**：`sample_status`、`sample_items`、`recipient`、`date`、`evidence`。

#### 4. 销售地 / 最终市场

- **为什么**：市场决定法规、语言、标签、价格带和受众；出口不等于欧盟，东盟不是一个国家。
- **看什么**：最终销售国家/地区、生产地、出口/内销、客户总部 vs 销售地、是否多市场。
- **不要**：看到“出口”就默认欧盟/美国；把客户所在地当销售地；把“东南亚”当一个统一法规区。
- **输出**：`target_market`、`regulatory_jurisdiction`、`market_notes`。

#### 5. 产品受众画像

- **为什么**：年龄、性别、敏感人群、婴童/宠物、渠道会改变香型、法规和宣称。
- **看什么**：成人/儿童/婴童、男士/女士/中性、敏感肌/头皮/口腔、宠物/猫砂、专业线/大众线、高端/性价比。
- **不要**：从“香型柔和”推“儿童可用”；从“母婴品牌”推所有产品都适用于婴童；从“男士”推具体香型。
- **输出**：`audience`、`age_group`、`sensitivity`、`channel`、`evidence`。

---

### P1：影响选香、报价和合规

#### 6. 价格要求

- **为什么**：价格决定可用的原料档次、配方复杂度和推荐范围。
- **看什么**：目标价/报价/成交价/样品金额；币种；元/kg 还是元/样品；含税/未税；数量/起订量；是否含包装/运费。**原文没有单位的报价数字，默认按元/公斤（香精单价）理解**；若上下文明确是成品/零售/样品金额，另记并待确认。
- **不要**：把样品金额当公斤价；把目标价当报价；把区间“100–200”取中值 150；人民币/美元混用；把无单位数字当“单位不明”而拒绝解析。
- **输出**：`price_type`、`amount`、`currency`、`unit`、`tax`、`quantity_basis`、`source`。

#### 7. 法规要求

- **为什么**：同一个香精在不同市场/品类/用量下结论不同。
- **看什么**：市场、产品品类、最终用途、香精在成品中的浓度、IFRA 类别/版本、过敏原、SDS/COA、注册/备案、儿童/口腔/消杀/驱蚊等特殊路径。
- **不要**：把 IFRA 当全球法律；把 SDS 当合规批准；把一次报告套到所有市场；把“天然来源”当法规豁免。
- **输出**：`regulation`、`market`、`category`、`usage_level`、`version`、`status`。

#### 8. 产品宣称

- **为什么**：宣称决定证据、法规路径和可用的香精/原料；内部概念不等于对外宣称。
- **看什么**：宣称原话、宣称对象（产品/成分/功效）、市场、是否有证据、是否已撤回、是内部提案还是对外承诺。
- **不要**：把“闻起来天然”写成“天然成分”；把“留香久”写成“24h”；把客户内部概念当对外宣称。
- **输出**：`claim_text`、`claim_type`、`market`、`evidence_status`、`external/internal`。

#### 9. 表现力要求

- **为什么**：强度、爆发、扩散、留香、平衡、层次是不同维度，且依赖阶段/载体/剂量。
- **看什么**：客户原话（“开盖要香”“不要太冲”“第二天还能闻到”）、评价阶段（开盖/使用/冲洗/干燥/后续）、载体、剂量、参照、测点。
- **不要**：把“留香久”默认 24h；把“爆发好”当“全程强”；把原液表现当应用表现；把一次主观舒适当安全结论。
- **输出**：`performance_dimension`、`target`、`stage`、`carrier`、`dosage`、`method`、`evidence`。

#### 10. 稳定性 / 相容性要求

- **为什么**：香精在原液、基料、包装、储运中的表现不同；没有条件就没有结论。
- **看什么**：基料/溶剂、加香比例、加入步骤、温度/光照/循环、包装材质、观察项（变色、浑浊、分层、析出、黏度、气味变化）、测试周期。
- **不要**：把“原液稳定”当“成品稳定”；把室温观察当高温/光照；把一次测试当所有包装。
- **输出**：`stability_scope`、`base`、`dosage`、`conditions`、`observations`、`status`。

#### 11. 对标样与对标目的

- **为什么**：对标目的决定能不能迁移 C、能不能叫“仿香”、要不要做相似度/差异分析。
- **看什么**：对标品牌/产品/版本；客户原话是“就要这个味”“像这个”“参考这个风格”“竞品分析”“只想借名字”；是否有实物标样/链接/图片；是否要求相似度、差异点、成本替代。
- **不要**：把所有“提到某品牌”当仿香；把“风格参考”当同款；把“对标”当“客户已确认”；把品牌名拆成原料。
- **输出**：`benchmark_identity`、`benchmark_purpose`、`reference_type`、`evidence`。

---

### P2：影响执行和交付

#### 12. 使用场景 / 基料 / 加香比例 / 工艺 / 包装

- **为什么**：同一香精在沐浴、洗衣、蜡烛、猫砂、面霜里的表现和法规不同。
- **看什么**：产品剂型、基料、加香比例、加入温度/步骤、灌装/包装、使用方式（冲洗/驻留/燃烧/喷雾/加热）。
- **不要**：把“香水”直接套到“洗衣液”；把“蜡烛”当“无火扩香”；把“加香比例”当“香精浓度”。
- **输出**：`application`、`base`、`dosage`、`process`、`packaging`、`usage`。

#### 13. 交付物 / 数量 / 时间 / 语言 / 标签 / 收件

- **为什么**：这些决定能不能按时交付，以及是否需要额外资料。
- **看什么**：原液/加香样/成品、数量/克重、截止日期、寄送/自提、收件人/地址、标签语言/法规标签、是否需要 SDS/COA/IFRA。
- **不要**：把“客户希望的时间”当“承诺交期”；把“寄样”当“交付资料”；把“英文标签”当“所有市场通用”。
- **输出**：`deliverable`、`quantity`、`deadline`、`shipping`、`label_language`、`documents`。

#### 14. 当前状态与确认方式

- **为什么**：候选、推荐、已寄、已试用、已确认、已选中是不同状态，不能混。
- **看什么**：谁确认的、什么时候、书面还是口头、是否有条件（价格/法规/稳定性）、是否有下一轮。
- **不要**：把“销售说客户喜欢”当“客户确认”；把“没回复”当“默认同意”；把“项目关闭”当“选中”。
- **输出**：`status`、`confirmed_by`、`confirmation_type`、`conditions`、`next_step`。

#### 15. 冲突、缺口与追问

- **为什么**：资料之间冲突是常态；静默合并会制造假事实。
- **看什么**：brief vs 会议、销售 vs 客户、旧版 vs 新版、价格 vs 成本、法规 vs 宣称、对标 vs 实际用样。
- **不要**：用“应该是”覆盖冲突；只保留一个来源；把不确定写成确定。
- **输出**：`conflicts`（双方原文+来源）、`open_questions`（按 P0/P1/P2）、`owner`（该问谁）。

## 四、信息成熟度标记

每个关注项建议用以下状态，而不是“有/无”二元：

| 状态 | 含义 | 例子 |
|---|---|---|
| `explicit` | 资料明确写了，且口径完整 | “目标价 80 元/kg，含税” |
| `partial` | 提到了，但缺口径/对象/条件 | “价格 80 以内”，按默认元/kg；税/数量未写 |
| `inferred` | 从上下文可合理推断，但无明文 | 从“出口欧盟”推欧盟法规，需标注推断 |
| `absent` | 资料没有出现 | 没有寄样记录 |
| `conflicting` | 多处说法不一致 | brief 写 24h，微信说“第二天就行” |

> `inferred` 只能作为“待确认”，不能直接当事实写进结论。

## 五、追问优先级

不是所有缺口都要追。按对下一步的影响分三级：

- **P0 阻断**：不确认就无法选香/报价/合规/交付。  
  例：产品品类不明、最终市场不明、对标目的不明、是否寄样不明。
- **P1 高影响**：会明显改变推荐范围或成本。  
  例：目标价区间、受众、法规路径、宣称、稳定性条件。
- **P2 执行**：影响交付细节，但不改变方向。  
  例：标签语言、收件人、包装、样品数量。

追问时只问“会影响决策的那一个”，不要一次把所有清单甩给客户。

## 六、常见句子的解读示例

| 资料原话 | 不要直接写成 | 应该怎么记 |
|---|---|---|
| “要一个大牌感” | 仿香某品牌 | 对标目的不明；记“风格/大牌感”，追问“像哪款/同款/只是风格” |
| “参考 XX 香水” | 仿 XX | 记“参考 XX”，目的待确认；不能直接迁 C |
| “寄了样品” | 客户已收到/已认可 | 记“已寄”；收到/试用/反馈分别确认 |
| “价格 100 以内” | 100 元/kg（无任何说明） | 记“≤100 元/kg（按无单位默认）；税/数量待确认” |
| “出口” | 欧盟法规 | 记“出口，最终市场待确认” |
| “留香 24 小时” | 已实现 24h | 记“目标 24h；载体/时点/方法待确认” |
| “客户说再看看” | 客户拒绝 | 记“未决定/待反馈” |
| “销售说客户很喜欢” | 客户确认 | 记“销售转述喜欢；客户书面确认待核” |
| “儿童可用” | 配方已符合儿童法规 | 记“宣称/目标儿童；年龄/法规路径待核” |
| “要便宜一点” | 目标价明确 | 记“价格压力；具体目标/单位待确认” |

## 八、一句话记忆

**看到就记，没看到就标无；先问口径，再问结论；不把目标当结果，不把转述当原话，不把对标当仿香。**
