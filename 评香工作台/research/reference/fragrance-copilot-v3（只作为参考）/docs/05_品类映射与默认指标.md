# 品类映射与默认指标 v3

理解节点从 category_map 的真实 K 码选择，程序统一物化三级品类、规范类和香精内部品类；无需再逐项调用品类模型。人工可从标准品类表修正。

默认内部品类硬筛，可多选或取消。每个香精主品类与记录在库的兼用品类均可构成适用范围。C 需求推断限于子项目主内部品类；换品类后旧 C 清理。

规范类默认指标沿用 v2 数据，包括 IFRA、过敏原、SDS/COA、地区要求、表现力与稳定性代码。检查按子简报市场及客户要求生成；要求内容变化会重置该项确认，不沿用旧确认结果。

默认规则只是执行核对清单，客户明确写的测试温度、周期、禁用物、颜色等以子项目专属要求保存，不被默认数值覆盖。
