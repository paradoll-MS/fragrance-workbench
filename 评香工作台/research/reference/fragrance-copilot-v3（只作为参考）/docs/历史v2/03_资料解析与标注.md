# 资料解析与标注

更新：2026-10-28

## 1. 支持输入

| 类型 | 当前处理 | 失败/降级 |
|---|---|---|
| PDF | 文本抽取、页码定位 | 扫描件标“待人工摘录” |
| Word / PPT / Excel | 段落/表格/备注抽取 | 复杂图表保留原件 |
| 文本 / Markdown / CSV / JSON | 直接读取 | — |
| 图片（截图/产品图/包装） | 保存原件；可点“识别/转写”走 Qwen VL | 失败保留原件，人工摘录 |
| 音频（会议） | 保存原件；可点“识别/转写”走 Qwen ASR（≤7MB/5分钟） | 失败要求纪要文字 |
| 视频 | 保存 | 第一版不做视频理解 |
| 对标链接 | 抓取网页正文 | JS 页面可能抓不到，保留链接+人工摘录 |
| 销售文本框粘贴 | 直接存为资料 | — |

## 2. 标注字段

- `source_type`：客户brief / 会议纪要 / 对标链接/图片 / 微信 / 销售输入 / 系统记录 / 寄样 / 报价 / 法规/检测 / 内部评香 / 邮件/附件 / 其他。
- `role`：需求 / 参考 / 反馈 / 法规 / 物流 / 外观 / 分析报告 / 其他。
- `free_tags`：自由标签（不强制套固定类）。
- `note`：附件备注，例如“PDF 第 3 页添加量有误”。
- `confidence`：分类置信度。

## 3. LLM 节点

`prompts/classify_artifact.md`  
输入：文件名、用户备注、文本（截断）；输出 JSON。  
分类不确定 → “其他”，不硬套；评香可改。

## 4. 规则

- 原件不可变；解析失败不丢原件。
- 图片 OCR/描述、语音转写是“辅助文本”，不能冒充客户原话；引用时标明来源。
- 会议里说“PDF 第几页有误” → 写进附件备注，不改原 PDF。
- 资料类型影响后续证据权重，但最终以原文为准。

## 5. 当前限制

- 视觉/ASR 未接；需确认模型与 key 后补 `artifacts/{id}/enrich`。
- 链接抓取不执行 JS；失败时人工粘贴正文。
