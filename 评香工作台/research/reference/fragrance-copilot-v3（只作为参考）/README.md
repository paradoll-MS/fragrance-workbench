# 香精项目 Copilot v3

在 v2 基础上重构，保留资料和香精数据，独立运行。

双击 `启动.cmd`，打开 http://127.0.0.1:8768 。v2仍使用8767，数据互不混用。

上传资料后点“开始自动生成”，一次完成项目故事、简报、子项目、ABC、推荐或参考候选和执行入口；继续上传反馈后再次生成，创建关联后续或补充已有任务。

客户身份、项目对接人与总体交期保存在项目；客户额外要求、具体产品/气味/基质/局部交期保存在适用子项目，并带来源进入工单。人工可改简报、条件、标签和硬筛。全部默认硬筛可取消。

两类推荐共用两轮计分：直接 A/B/C = 1/1/3（硬筛标签本身不计）；需求C关联出的AB与候选自身A/B匹配，每个distinct AB命中+1。显示候选自身ABC、分数、用样次数。

任务按依赖推进，GC完成由人工确认并自动接续调香。入库界面及后端均关闭，香精库不写入。

本地模型配置沿用 data/config.json。原件和业务库位于data，网页为web。模型故障、输出不完整或生成期间发生人工修改时保留旧结果并显示原因。

逐本保留12个首轮香型 + 4个关联改香；此前101/74项结构流程检查不代表业务语义已验收，三调与额外需求边界校正后需重新验证。见 [逐本两轮验收](docs/逐本两轮验收.md)。

关联改香自动承袭首轮实际寄样号；样例缺号时保留原样引用并等待同步。寄样工单可填写实发调香试样号，不写库。

现行业务规则见 [business_rules.md](spec/business_rules.md)：三调仅辅助BC；A须有独立的主韵/主体气味依据；额外需求只收文件证明、认证、对外宣称。旧生成结果标记待重新理解，不复用旧语义缓存。
