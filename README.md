# 交付总控

一个本地项目，加两份只读资料库。

- [评香工作台](评香工作台/README.md)：应用本体。双击 [启动.cmd](评香工作台/启动.cmd) 进入项目列表；分层与依赖在 [architecture](评香工作台/docs/architecture.md)，需求字段与打标在 [intelligence](评香工作台/docs/intelligence.md)，能证明什么在 [本机验收](评香工作台/docs/acceptance.md)。
- [评香工作台/docs](评香工作台/docs)：业务标准、设计、验收、取舍都收在这里。[wanted.txt](评香工作台/docs/wanted.txt) 是标准，[thinking.md](评香工作台/docs/thinking.md) 是取舍来源，[第一轮设计](评香工作台/docs/设计历史/第一轮设计/README.md) 是重搭前的历史。
- [resources](评香工作台/resources)：[ABC 库与字典](评香工作台/resources/ABC/README.md) 与 [审查规则](评香工作台/resources/审查)，随应用归档，运行时只读。
- [research/cases](评香工作台/research/cases)：[真实案例](评香工作台/research/cases/真实案例) 与 [历史工单](评香工作台/research/cases/项目工单数据)，用于还原输入与逐案核对。
- [research/reference](评香工作台/research/reference)：旧版 [V3](评香工作台/research/reference/fragrance-copilot-v3（只作为参考）)，只作对照。
- 本机凭据放在既有的 API 密钥配置目录。
