# UI 信息架构（v2）

更新：2026-10-28

## 1. 原则

- 一屏一个主要任务；默认只显示“下一步”。
- 不再做全量树、左侧大目录、多个并排面板。
- 低频字段折叠；推荐结果一张表；解释点开看。
- 所有人工确认可见，LLM 输出不直接改事实。

## 2. 五屏

### 1）项目列表

- 项目卡片：名称/客户/状态/子项目数/更新时间。
- 新建项目。
- 空状态：直接新建。

### 2）项目工作台

顶部项目摘要 + 三个 tab：

- **资料**：粘贴/上传/链接；资料卡（类型、角色、状态、备注）。
- **项目简报**：关键字段 + 完整 JSON/证据；按资料生成；保存。
- **子项目**：按资料拆分 / 手工加；卡片显示类型/状态/新类/价格。

### 3）子项目详情

- 顶部：标题、主类型、状态、新类、终点。
- 条件区：L3、目标价、规范类/新类、目标 C、品牌、A1。
- 推荐区：跑推荐 → 表（#、香精、C、AB 分、价格、标签、依据）。
- 任务区：生成默认任务、推进状态。
- 侧栏：终点、外部样品、当前条件。

### 4）推荐结果

- 一行一个候选；分数、AB 命中、价格差、标签。
- 默认排序：品牌推荐 AB 分降序；简单推荐价格升序。
- 点行展开解释；可短名单/淘汰（后续）。

### 5）故事与问答

- 故事：资料/简报时间线 + 原文摘录。
- 问答：问题 + 答案 + 引用；没有资料就直说。

## 3. 自动生成与 ABC 映射

- 点“项目简报”时，若简报为空且已有资料，自动生成；点“子项目”时，若还没有子项目，自动拆分，不需要先按按钮。
- 自动生成失败/超时：先用规则预填，页面明确标“规则预填”；用户可再点“重新按资料生成”。
- 子项目详情在推荐前显示“ABC / 香型映射”卡：
  - A1/A2/A3 的标签/路径；
  - 目标 C 与 C 固定 AB；
  - A1/A2/A3 可改用中文或 id；C 可下拉调整。
- C 未确定时推荐按钮可以点，但会提示先定 C；不会拿空 C 硬跑。

## 4. 省略/折叠

- 完整 JSON、证据、模型原始输出放 details。
- 低频法规/稳定性字段在简报高级区。
- 不把品牌历史、全量标签、所有任务都铺在首屏。

## 5. 响应式

- 桌面 2 栏（主内容 + 侧栏），窄屏单栏。
- 推荐表横向滚动；不做固定大表头。
