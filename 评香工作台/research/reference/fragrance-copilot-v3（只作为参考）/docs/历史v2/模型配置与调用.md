# 模型配置与调用

更新：2026-10-28  
目标：只改 `data/config.json` 就能换 API / 模型，不需要改代码。

## 1. 配置文件

```json
{
  "providers": {
    "deepseek": {
      "base_url": "https://api.deepseek.com",
      "model": "deepseek-v4-pro",
      "api_key": "sk-..."
    },
    "qwen": {
      "base_url": "https://dashscope.aliyuncs.com/compatible-mode/v1",
      "model": "qwen3.8-max",
      "api_key": "sk-..."
    }
  }
}
```

- 两个 provider 都是 OpenAI 兼容接口。
- 改 `api_key`、`base_url`、`model` 后，下一次请求生效；不需要重启服务。
- 环境变量 `DEEPSEEK_API_KEY` / `QWEN_API_KEY` 会覆盖文件中的 key。
- key 不会返回浏览器，不写日志/导出。

## 2. 节点用哪个模型

| 节点 | 当前调用 | 建议模型 | 说明 |
|---|---|---|---|
| N01 资料分类 | DeepSeek/千问文本 | deepseek-v4-pro 或 qwen3.8-max | JSON 输出 |
| N02 项目简报抽取 | DeepSeek/千问文本 | deepseek-v4-pro | JSON；失败自动切千问 |
| N04 子项目拆分 | DeepSeek/千问文本 | qwen3.8-max | 长上下文更稳 |
| N07 目标 C 映射 | 千问优先 | qwen3.8-max | JSON，只选一个 C |
| N11 项目问答 | DeepSeek/千问文本 | deepseek-v4-pro | 主要看检索质量 |
| 图片视觉 | Qwen VL | qwen3-vl-plus | 需视觉额度；失败保留原件 |
| 音频转写 | Qwen ASR | qwen3-asr-flash | 需 ASR 额度；≤7MB/5分钟 |

## 3. 调用约定

- `app/llm.py`：
  - `chat()` 文本；
  - `chat_json()` 强制 JSON，失败/空返回自动切千问重试；
  - `vision()` 图片（预留）。
- 每次请求超时 180 秒；长文档先截断，超出请拆分。
- 提示词在 `prompts/`；改提示词不需要改代码。

## 4. 换模型

1. 改 `data/config.json` 对应 provider 的 `model`；
2. 如果模型不支持 JSON mode，`chat_json` 会尝试从返回中截取 `{...}`；
3. 如果模型名/网关变化，改 `base_url`；
4. 若新 provider 不是 OpenAI 兼容，需要在 `app/llm.py` 增加适配器，不能只改配置。

## 5. 当前限制

- 图片/音频只保存并提示，未接视觉/ASR；需要你确认是否用 Qwen VL / ASR 及对应 key。
- 链接抓取只取网页正文，不渲染 JS；失败保留链接+人工摘录。
- 所有 LLM 输出都要经过人工确认，不直接改事实。
