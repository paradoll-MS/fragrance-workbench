# 任务派发与完成终点

更新：2026-10-28

## 1. 六类子项目 → 部门任务

| 子项目 | 默认部门任务 |
|---|---|
| 找一个香 | 打样、寄样、调香、法规、质量 |
| 对一个香味 | 打样、寄样、分析、调香、法规、质量 |
| 推荐·简单厂家 | 寄样、打样、法规、质量 |
| 推荐·品牌客户/创香前 | 寄样、打样、法规、质量 |
| 改香 | 调香、入库、法规、质量 |
| 创香 | 寄样、打样、法规、质量、调香、入库 |

部门任务字段：类型、标题、负责人/部门、截止、状态、依赖、payload、结果。

## 2. 终点

| 终点 | 条件 | 谁确认 |
|---|---|---|
| `sample_initial` 初样 | 只闻香；法规/稳定性/表现力只提示，不阻断 | 评香放行并留原因 |
| `sample_final` 终样 | 三项默认逐项核对；缺项不能完成 | 评香确认 |
| `library_intake` 入库 | 同终样；生成配方登记信息，不做实物库存 | 评香确认 |

## 3. 规则

- 没有寄样记录不能把 `match_sample` 标完成。
- 初样放行不是“合规通过”，只代表允许先闻香。
- 终样/入库缺法规/质量任务不能完成；可人工 override，但必须记录原因。
- 任务状态：todo / doing / waiting / done / cancelled；waiting 写等什么。

## 4. 当前实现

- 默认任务由 `spec/v2_task_types.json` 生成。
- 终点检查：初样提示；终样/入库检查法规/质量任务是否 done。
- 终点接口同时返回该规范类的默认指标：IFRA、过敏原、SDS/COA、表现力 P 码、稳定性 S 码、按销售地的法规明细（读 `data/规范类默认指标.json`）。
- 默认指标按 IFRA/过敏原/SDS/地区法规/P 码/S 码生成 `endpoint_checks` 逐项清单；每项可标“确认/不适用”，终样/入库必须无 pending。
- 客户资料里逐条写明的检查项（禁用物、IFRA51、REACH、闪点、26/82 过敏原等）单独建 `source=customer` 条目，保留原文明细，前端红色高亮；不与默认指标混为一条。
- 自动判定仅到“任务完成 + 逐项已核对”；具体数值是否满足仍由评香/法规人工确认。
