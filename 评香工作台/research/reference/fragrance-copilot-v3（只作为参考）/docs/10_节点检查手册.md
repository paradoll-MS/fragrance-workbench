# v3 检查入口

- GET /api/projects/{id}：项目、资料、子项目、项目简报和生成状态。
- POST /api/projects/{id}/generate：完整/增量理解。
- GET /api/projects/{id}/generation：持久运行状态。
- GET /api/projects/{id}/story：故事和覆盖说明。
- GET /api/subprojects/{id}：子简报、候选快照、任务、样品和检查。
- GET /api/subprojects/{id}/abc-map：需求ABC和依据。
- POST /api/subprojects/{id}/recommend：确定性推荐/参考检索。
- POST /api/subprojects/{id}/workflow：select / analysis。
- PATCH /api/tasks/{id}：任务状态与结果。
- POST /api/tasks/{id}/files：分析附件。

数据库中 generation_runs 保存完整输入、成功输出或被拒绝输出及错误；brief_history 保存简报版本；decisions 保存人工和模型应用；recommendations 保存算法与筛选快照；task_files 保存报告。

运行 `python tests/test_v3.py` 验证计算、依赖、分层、并发和接口。逐本案例的原文、首轮快照与两轮检查结果在 data/verification/逐本；报告见 docs/逐本两轮验收.md。
