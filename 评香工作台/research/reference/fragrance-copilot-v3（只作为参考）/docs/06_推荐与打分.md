# 推荐与打分 v3

## 硬筛

内部品类默认勾选、可多选 OR；价格默认勾选，上限为目标价×(1+t%)，滑条初值 t=20%，允许 0–200%。无目标价不限制；有价格硬筛时，库中未知价不当作已通过。

A1 存在时默认 OR；否则 A2/A3 合并 OR。取消 A1 硬筛不会暗中启用 A23。B/C 默认不硬筛；可手动锁 ABC 中任意标签。同组 any 为 OR、all 为 AND，不同组全部满足。

厂家额外默认启用明确提出的大牌/品牌分支、爆品、新品；品牌每个分支只保留最细层级，分支间 OR。爆品和新品两个开关都启用时需同时满足，可分别取消。具体产品必须拆成找香。

## 两轮计分

第一轮：候选自身 ABC 与当前需求 ABC 比较，distinct A/B/C 命中分别 +1/+1/+3；被用作硬筛的标签本身不计直接分。C 选父节点时可命中其后代。

第二轮（2026-10-30 用户纠正）：取需求 C 直接关联的 AB 并集，与候选自身已有的 A/B 比较，每个 distinct AB 命中 +1。同一AB被多个需求C关联时只计一次，并保留全部来源需求C。不从候选C反推AB，也不自动把未选择的子C之关联AB加入需求。映射分与直接分独立，硬筛 AB 仍可在映射轮加分。

两类推荐使用同一计分。总分降序 → C 分降序 → 已知价格优先/价格升序 → 在库用样次数 → 编号。最多显示前100条，保留总候选数与逐级排除数量。

## 展示和留存

显示自身 ABC、直接 A/B/C 分、需求 C 关联 AB 命中候选的分数及链路、总分、价格、爆/新/大牌、用样次数。推荐快照记录条件、算法与候选标签，重新打开不丢分数。相同条件复用推荐，短名单和淘汰决定跨重算保留。

找香先按品牌—规范产品目录解析名称：库内双语名、常见写法和应用层已确认别名共用同一解析器；Le Labo+13在品牌内编号唯一时可解析为Another 13，不能用无品牌的%13%匹配113或其它产品。有重名则列歧义，不猜；未验证版本不当作同款。先统计库内身份存在，再应用当前品类/价格筛选，并分别展示被排除的记录。创香/改香的库内结果为参考候选；对香结果为标签检索，不替代评香的相似性判断。
