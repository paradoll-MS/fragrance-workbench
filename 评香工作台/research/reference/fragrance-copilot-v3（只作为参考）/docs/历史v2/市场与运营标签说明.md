# 香精市场与运营标签说明

生成：2026-10-28　|　独立于 A/B/C，不改变任何 ABC 标签

## 一、两个独立标签组

### 1. 大牌仿香 / 品牌标签

**数据来源**

- 中央库 WIP `【wip】中央闻香库20260623.xlsx` 的“借鉴品牌 / 借鉴产品名称”（191 条）；
- 历史库 `brand_product_labels`（2,865 条已有语义标注）；
- 关系类型：`借鉴`、`仿香对象`、`名称明确同款`、`同款指认` 记为**大牌仿香**；
- `近似参考`、`风格参考`、`母方参考` 单独记为**大牌参考**，不混入仿香。

**结果**

| 指标 | 数量 |
|---|---:|
| 大牌仿香香精 | **1,283** |
| 仅大牌参考（非仿香） | 395 |
| 品牌标签数 | **250** |
| 有仿香标签但无品牌 | 0 |

- 每个号保留全部 `brand_tags`；`primary_brand` 按“借鉴 > 仿香对象 > 名称明确同款 > 同款指认 > 参考”取第一个。
- 具体产品保留 `brand / product / relation / source`，可追溯到中央库或原语义标注。
- 一个号可以有多个品牌标签；不强行合并成单一品牌。

### 2. 爆品 / 新品（可同时为真）

**中央库原标注优先**

中央库 WIP 的 `入库逻辑` 字段：

| 入库逻辑 | 数量 | 含义 |
|---|---:|---|
| 爆品 | 1,171 | 中央库原标注爆品 |
| 新品 | 265 | 中央库原标注新品 |
| 评香库积累 | 1,779 | 非爆品/新品 |
| 赵倩库捡回 | 675 | 非爆品/新品 |

**工单关联补充爆品**

- 统计每个号关联的**不同工单数**；≥5 个工单记为“关联工单较多”，补为爆品。
- 5 个是本次分布的经验阈值（约 95 分位：≥5 的号 211 个；≥3 的 430 个）。
- 其中 161 个号不是中央库原爆品，由工单数补入；与中央库爆品合并后：

| 指标 | 数量 |
|---|---:|
| 爆品（中央库 + 工单≥5） | **1,332** |
| 其中中央库原爆品 | 1,171 |
| 其中工单补爆品 | 161 |
| 新品（仅中央库原标注） | **265** |
| **爆品 + 新品** | **83** |

- `is_hot` 与 `is_new` 不互斥；83 个号同时为真。
- 新品本轮**不**从工单时间推断，只保留中央库原标注；避免把“最近有工单”误当新品。
- 每个号保留 `work_order_count`、`hot_sources`、`new_sources`，可复核。

## 二、存放位置

- JSON：`data/香精ABC关联.json` 每个 formula 的
  - `market_labels`
  - `ops_labels`
- SQLite：
  - `formula_market_labels`
  - `formula_operation_labels`
- 独立索引页：`香精市场与运营标签.html`
- ABC 详情页顶部也会显示标签 chip（如 `大牌仿香 · 爱马仕 Hermès`、`爆品`、`新品`）。

SQL 示例：

```sql
select f.code, f.name, m.is_brand_dupe, m.primary_brand,
       o.is_hot, o.is_new, o.work_order_count
from formulas f
left join formula_market_labels m on m.code=f.code
left join formula_operation_labels o on o.code=f.code
where m.is_brand_dupe=1 and o.is_hot=1;
```

## 三、口径边界

1. **大牌仿香不等于“所有品牌参照”**：近似参考/风格参考进入“大牌参考”，不进入仿香。
2. **爆品是“中央库原标注 ∪ 工单≥5”**，不是销量预测；工单多只代表内部被推荐/使用得多。
3. **新品只认中央库原标注**；没有原标注的号不因工单新就标新品。
4. 一个号可有多个品牌、可同时爆品+新品；不强行二选一。
5. 原有 `brand_product_labels` 的关系和品牌保留；本层只做汇总，不覆盖原标注。

- `60028 美丽人生`：`大牌仿香 · 兰蔻 Lancôme`；具体产品 `兰蔻 Lancôme-美丽人生`。
- `1040 香柠檬`：中央库原 `爆品`，但没有具体品牌仿香，因此只显示爆品、不硬造品牌。
