# 评香工作台

双击 [启动.cmd](启动.cmd)，服务就绪后会自动打开项目流程。重复运行会复用已启动的服务，关闭启动窗口后仍可访问。若启动失败，查看 `data/startup.log`。首次需要安装 `python -m pip install -r requirements.txt`。

- [项目流程](http://127.0.0.1:18761/projects) 可新建项目、提交资料、审阅草案、建立轮次、执行选香或开发，并查看模拟实发。
- [选香](http://127.0.0.1:18761/) 提供常规推荐、品牌推荐、对香和精确找香。从项目方向进入时，沿用其品类、价格和产品条件，选定后回项目流程。
- [模拟中台](http://127.0.0.1:18761/mock-platform) 合并部门任务、数据回流、模拟报价、香精库与权重试算、字典查询。部门可以单条通过或退回，也可以为新任务设默认回执。权重试算使用当前库和人工覆盖，本次试算参数独立于主页面配置。
- [选香试跑](research/recommendation-推荐试跑.md) 和 [主任务验收](research/acceptance-主任务验收.md) 存对照结果。默认权重在 [scoring.json](scoring.json)，链路见 [平台主流程](workflow-平台主链.txt)。
- 本地状态与上传原件默认保存在 `data/workspace.sqlite3`。可用 `--database` 指定试验数据库。ABC、工单库、审查字典作为只读资料。拆解用 Paratera；选「使用 Paratera 读取图片和扫描页」时才发送图片。标签先走唯一字典匹配。
- Python 代码在 `app/`，两个站点在 `web/`，测试在 `tests/`。运行 `python -m unittest discover -s tests -v` 会使用临时数据库。

## 模拟中台读写时机

1. **检索时读**。香精编号、名称、ABC、应用品类、标记和确认关系来自字典及资产，模拟报价覆盖只读库价。报价以元/kg 输入。清空模拟报价恢复库报价。
2. **评香决定时写**。保存项目、香精、检索快照、动作及说明。改资产标签带 manual 记录，回流看板能查增加或移除了哪些标签。修改当前需求筛选保存查询版本和项目反馈。
3. **派发与回执**。任务带部门、项目、动作、香精、说明、寄样形态与数量。回执是通过、退回或待处理；支持单条、批量通过和新任务默认回执。初寄在四种模式都可按模拟动作记录，提交表单只需填写所寄样品的形态与数量。
4. **模拟对象**。调香、入库、备样、寄样都生成带 `MOCK` 前缀的对象。模拟检查使用业务条件、审查类别和部门回执。真实可调用配方、实物库存、正式质检凭证及物流需要接入中台。
