## 先读哪几份

- [wanted.txt](wanted.txt)：业务标准原文，最高依据。字段、动作、判定都以此为准。
- [验收参考.md](验收参考.md)：六条验收点，用来判断「做完了没有」。
- [thinking.md](thinking.md)：文档写法与协作约定（`.txt` 用于逻辑链，`.md` 用于说明，不用表格）。
- [一个复杂度参考但是不代表完全合适的结构.txt](一个复杂度参考但是不代表完全合适的结构.txt)：目录复杂度的参考，不是硬性要求。

## 第一轮设计是历史

[第一轮设计](第一轮设计/README.md) 记录的是重搭之前的设计：对象、函数契约、主流程树、选香、数据、工作台、业务待定、路径验收。

它的价值是保留了当时的判断过程与业务细节；它的问题也被记在 [取舍](../评香工作台/docs/decisions.md) 与 [架构](../评香工作台/docs/architecture.md) 里。当前实现与它不一致的地方，以代码与 `评香工作台/docs` 为准：

- 对象与字段：以 [objects-对象与字段.md](第一轮设计/objects-对象与字段.md) 的语义为准，但表结构看 `app/store/schema.py`。
- 函数契约：F01–F24 的编号沿用，落点看 [functions.md](../评香工作台/docs/functions.md)。
- 主流程：阶段与动作看 [workflow.txt](../评香工作台/docs/workflow.txt)，第一轮的流程树留作对照。
- 选香：算法细节看 [recommendation-ABC选香.md](第一轮设计/recommendation-ABC选香.md)，实现看 `app/assets/ranking.py`。
