# 任务推进与终点 v3

## 路径

找香：精确检索 → 评香选香 → 打样；或评香提交分析 → 人工确认GC完成 → 自动调香工单（带产品、品类、基质、要求、分析附件）→ 评香验收 → 打样。

对香：登记收到外部实物 → 评香对香/标签检索 → 选择内部号打样，或提交分析后走同上路径。

两类推荐：理解与推荐 → 评香短名单/选定内部号 → 打样。

改香：内部号/原样与改动要求 → 调香。关联上一轮的改香自动承袭最近已完成寄样工单的实际寄出编号；无寄样记录时，两类推荐、找香、对香可使用上一轮已选定内部号。创香/改香的评香参考号不能冒充实发号。

上一轮编号尚未同步时保留原样、父子关系和改动要求，调香工单等待原样编号同步；首轮实发号补齐后自动唤醒。多个实发号而无法唯一对应时不猜测。只有独立发起且没有父项目引用的改香，才保留确认改香基准入口。

创香：完整需求与评香参考 → 调香 → 评香验收 → 打样。

共用后半程：打样完成 → 寄样任务；寄样完成 → 法规、质量任务；逐项核对后可完成终样。前置未完成不能将后续任务 doing/done。GC必须手动勾选确认，并记录结果。所有任务完成均需结果说明。

参考香保存只更新调香工单参考，不直接派发打样。

## 终点

初样需打样与寄样实际人工确认完成，并填写评香放行说明。终样需法规、质量任务 done、规范类/默认指标已知，以及客户和默认检查无 pending。不适用需说明原因。

入库始终关闭：按钮禁用，终点拒绝，不能通过子项目 PATCH 修改状态绕过，入库工单也不能标完成。不会将试用结果回写香精库。

实际寄样编号在寄样工单填写，支持真实调香试样号；它只进入项目执行记录，不自动创建香精库条目。待执行后续工单同步项目客户、项目对接与交期、子简报和原样引用。
