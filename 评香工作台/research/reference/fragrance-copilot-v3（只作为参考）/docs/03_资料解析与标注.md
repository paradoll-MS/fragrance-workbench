# 资料解析与标注 v3

支持文本、PDF、DOCX、PPTX、XLSX、图片、音频和 HTTP 链接；原件保留。DOCX 段落与表格按原始顺序读取。PDF 同时保留文字页和无文字页的扫描识别，不只看前四张图。扫描页缺失、容量截断和链接正文抓取失败会标 needs_text。

解析保存全文、页段定位、错误、接收时间和用户备注。初步分类失败单独留记录，不能抹去已经解析的文字。用户可补充摘录、改备注、重新解析。

完整理解时重新标注每一份资料，保存 source_type、role、summary、relation（首轮/补充/推进/参考/冲突）、关联子项目与引用。重新标注不覆盖原件和人工备注。

模型看到原文全文，不将视觉描述冒充客户逐字原话。对视频或无法读取的格式，保留原件并要求可读文本。
