# 模型配置与调用（2026-10-30）

默认全景理解继续使用现有 DeepSeek-V4-Pro，明确关闭 thinking。长上下文不等于必须开启长程思考；所有原始资料仍完整读取，关闭的是隐藏推理输出，不是删减资料。

可在data/config.json用understanding_thinking=true显式开启，understanding_reasoning_effort选择强度。输出上限默认小项目24000、较大项目48000，可用understanding_max_tokens覆盖。上限不是目标输出长度，不把提高上限作为常规修复。

小项目定义：≤4份资料、≤4个既有子项、原文≤6000字符。该规则只决定输出容量，不参与任务拆分或业务标签推断。默认不自动开启thinking。跨轮冲突的有界校验仍可单独使用深入推理。

图片读取用Qwen3-VL-Plus，关闭思考，只转写文字和有用证据，不输出套话或聊天气泡版式。原件保留，缺字标不清晰；达到识别输出上限视作不完整。

词表用可完整还原的列式表与C层级，标签、定义和父子关系均未删除。来源改为原文定位段source_id，由服务还原资料、页段与精确位置，避免模型反复抄长引文。六组简报由服务补全空值，模型只输出非空事实与共享部分的差异。

每次模型调用记录请求的thinking/max_tokens、finish_reason、输入/输出token、返回正文与思考字符数、以及供应商报告的reasoning_tokens（未报告则为空，不猜测）。只保存思考长度统计，不保存思考全文。截断时保留不完整业务JSON供诊断，不写入项目结果。

chat_json不再无差别跨模型重跑，避免一次失败后隐蔽地再等待一整轮。同项目只允许一个活跃生成任务；无变化时复用成功结果，业务规则或来源格式版本变化时重新理解。服务更新需要重启进程才能生效。

权力案例的模型对比见《模型调用修正与复测_20261030.md》。Flash更快，但本次出现无依据的A3泛化，暂不取代默认模型。
