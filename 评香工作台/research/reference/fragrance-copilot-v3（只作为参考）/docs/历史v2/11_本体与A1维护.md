# 本体与 A1/A2/A3 维护

更新：2026-10-29

## 1. 本体层级

- A1：具体原料/香材，是**方向词的本体**（南瓜、芫荽、欧芹、玫瑰……）。
- A2：上位香调/家族（花香、果香、草本、辛香料……）。
- A3：更宽的修饰或场景标签。

一个方向“香菜”不是没有本体：它对应 **芫荽 A1**。  
“欧芹”此前不在本体里，属于**本体覆盖缺口**，不是“应该保持空”。

## 2. 系统怎么解析方向

`app/server.py::_direction_tags`：

1. 先按 A1 label 精确匹配；
2. 再查 `term_aliases`（香菜→芫荽、香芹→芫荽、欧芹→欧芹……）；
3. 具体单原料词仍无本体时，自动创建 `A1_custom_*`，标为“方向词自动补充的本体；待评香确认”；
4. 花香/果香/草本/其他/推荐这类宽方向不强行造 A1，只做 A2 建议。

## 3. 数据表

- `terms`：本体节点（A1/A2/A3）。
- `term_aliases`：别名，`alias -> term_id`。
- `library_tags`：香精的 A/B 标签。

`scripts/build_library.py` 已包含 `term_aliases` 建表和香菜/欧芹的种子别名，重建库不会丢。

## 4. A1 硬筛开关

A1 默认是硬筛，子项目条件里有 **“A1 硬筛（默认勾选）”**：

- 勾上：候选必须命中任一 A1；多个 A1 是“任一命中”；
- 取消：不按 A1 硬筛，按 A2/A3 宽筛；
- 默认值写入 `subprojects.a1_hard=1`，旧子项目迁移也为 1；
- 本体存在但香精还没打标时，勾上可能 0 候选，这是数据缺口，不要静默放宽；UI 会显示匹配数，需补标签或取消硬筛。

宽方向词如“花香-草本”没有 A1，不强行造 A1，按 A2 建议/宽筛。

## 5. 维护动作

新增原料时：

1. 能复用已有本体就加到 `term_aliases`；
2. 确实没有本体才新增 `terms` A1；
3. 给这个 A1 补香精标签；
4. 回归 `南瓜/香菜/欧芹` 这类方向，确认 A1 不是空。
